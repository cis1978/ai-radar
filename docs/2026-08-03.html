Excelが「SKILL.md」を読み始めた

2026年8月3日（月）

Excel の Copilot が SKILL.md を読むようになった。Claude・Slack・Excel が同じ「手順をMarkdownで書いて渡す」形式に揃った。
前号で「業務手順を文書化せよ」と書いたが、その文書がそのまま3つのツールで動く資産になったということ。

01Excel Copilot のカスタムスキルは「OneDriveに置いた SKILL.md」

Microsoft が Excel 向けに skills を導入した。DCF構築、月次決算、レポートモデルの更新、差異分析といった繰り返し業務について、Copilotに踏ませる手順を定義できる。

決定的なのは実装形式で、オープン標準のMarkdownファイルである。OneDriveに SKILL.md を保存するとCopilotが拾い、定義した手順どおりに三表モデルや取締役会資料を組み立てる。プロンプトからは @variance-analysis @model-update のように呼び出す。

サンプルのfinance skillsライブラリは提供済み。カスタムスキルはWindows/Mac の Insiders で利用可能、来月Web含めGA予定。パートナー製スキルは2026 Q3。

転用アイデア

前号の「業務手順を文書化してスキル化する」が、Excelでも同じファイル形式で通るようになった。まず1本書けば、置き場所を変えるだけで使い回せる。 shujiさんが毎月やっている集計や差異チェックがあれば、そこが最初の1本の候補。

出典: Copilot in Excel: Built for the era of Frontier Finance / スキルの作成・管理ドキュメント

02「提案するAI」から「手を動かすAI」への転換が、数字で出た

Word・Excel・PowerPoint のエージェント機能がGAし、全Microsoft 365サブスクリプションでデフォルト体験になった。Microsoftが公表したGA後1ヶ月の変化:

アプリ利用頻度（週あたり/ユーザー）新規ユーザー継続率満足度（👍率）
Word+52%+11%+21%
Excel+67%+50%+65%
PowerPoint+11%+36%+25%

Microsoftが挙げた学びのうち2つが実務的に重要。「手順を提案するのではなく作業を実行したときに価値が出る」、そして「制御は譲れない — 何が変わったかレビューできること」。後者への回答が「Plan with Copilot」（着手前にどのセル・数式を変更するか提示）と、変更履歴でのCopilot帰属表示。

転用アイデア

Excel の伸びが突出している（継続率+50%、満足度+65%）のは、表計算が「正解が検証できる作業」だから。成果を確かめやすい業務からAIを入れるという順番の裏付けになっている。ふわっとした企画業務より、数字が合うか合わないかが分かる作業のほうが定着する。

出典: Copilot's agentic capabilities in Word, Excel, and PowerPoint are generally available

03長時間タスクの鍵は「圧縮」ではなく「コンテキストのリセット＋引き継ぎ資料」

長く走らせるエージェントの根本問題は、セッションが切れると記憶がゼロに戻ることにある。Anthropicの設計知見は、会話を要約して引き延ばす（compaction）のではなく、意図的にコンテキストをリセットし、次のセッションが読む引き継ぎ成果物を残すという方向。

構成は2種類のエージェント。初回に環境を整える初期化エージェントと、毎回少しずつ前進させて次回用の成果物を残す実行エージェント。作業を扱えるサイズに分解し、状態を構造化した成果物として受け渡す。

転用アイデア

これは人間の引き継ぎとまったく同じ構造で、AI以前の業務にも効く。長い作業を頼むときは、会話を続けようとせず「ここまでの結論をファイルに書き出して」と言って一度切る。 前号のAI Radarもこの形（config.md ＋ 過去の号を毎回読み直す）で作ってある。

出典: Effective harnesses for long-running agents / Effective context engineering for AI agents

04Excel が外部データソースに直結し始めた

5月のLSEG・Moody'sに続き、Copilot in Excel の金融データコネクタが拡張された。CB Insights（未上場企業の予測インテリジェンス）、Daloopa（SEC提出書類由来の監査対応可能なファンダメンタルズ）、FactSet（7月GA予定）、Morningstar、PitchBook、S&P Global。手作業でのデータ取得を挟まず、最新ソースから分析を始められる。

※ サードパーティコネクタは提供元との別途契約が必要。

転用アイデア

金融データそのものより、「手でコピペしていた外部データをコネクタ経由に替える」という発想が転用可能。shujiさんの業務で毎回どこかから転記している数字があれば、それがボトルネックであり自動化の起点。

出典: Copilot in Excel: Built for the era of Frontier Finance / LSEG・Moody's コネクタ（5月）
